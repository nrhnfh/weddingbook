🔗 Generate Link Undangan Digital

📌 Cara menggunakan:

  1. Buka Google Sheets → sheet daftar_tamu
  2. Blok semua data (Ctrl+A) → Copy (Ctrl+C)
  3. Paste ke text area di bawah (Ctrl+V)
  4. Klik Generate Link
  5. Klik Export Excel untuk download
